# 节日表情

节日需求按**聊天用途**组织，不只罗列节日活动。同一个节日，先保证用户发得出去：

| 用途 | 例子 |
| --- | --- |
| 发祝福 | 吉祥话机关枪、递平安果 |
| 回祝福 | 嘴里塞满饺子抱拳回礼 |
| 讨红包、谢红包 | 端碗讨红包、拆红包被金光闪到 |
| 婉拒、吐槽 | 裹成春卷躲拜年、亲戚三连问 |
| 报平安、约饭 | 到家瘫倒比 OK、举着饺子探头 |
| 温情 | 视频给爸妈比心、值班有人递饺子 |

用 `python scripts/action.py --family christmas|newyear|spring --list` 查节日卡，`--list-packs` 查节日包和适用时段。用户没说用途时，一组里混合发祝福、回祝福和吐槽，不要整组都是同一种。

## 换主体和换形式

- **主体：** 宠物抢年夜饭、食物拟人吵架、红包长腿跑走、纯文字被鞭炮崩散、写实照片身后放烟花，都能演同一个节日。
- **画风：** 发给长辈时可以用“长辈问候图”风格，金光大字、荷花玫瑰，真诚或恶搞都行。
- **温情款：** 回不了家、过节值班这类内容不必好笑，用“真诚”笑点即可。

## 组合表情

有些卡是两张连发才完整的笑点，比如“给你发红包”接“红包又收回去”。导演说明会写明这是第几张、另一张是哪张。用户选中其中一张时，两张都做，按顺序交付，并告诉用户要连着发。

## 个性化叠字

用户给出名字或专属祝福时，用叠字工具写进画面，比如把对方的名字写在春联横批上。模型生成时留出空白位置，不让它画字，出片后用 `caption_gif.py` 叠加。

## 每年都能用

- **生肖不要写死：** 用姿势模板并换成当年的生肖，例如 `python scripts/action.py --template zodiac-greeting --slot zodiac=马 --character 戴红围巾的小马`。
- **年份由叠字填写：** 不在画面里写死某一年。
- **春节日期每年不同：** 节日包的适用时段是大致范围，按当年日历判断。

## 节日边界

- 圣诞只做世俗的节日场景，不涉及宗教内容。
- 放烟花和鞭炮只作为画面元素，不鼓励在禁放地区燃放。
- 不使用现成 IP 或品牌，例如生肖羊年不要用现成的动画羊角色；圣诞老人、麋鹿、年兽、财神这类通用形象可以用。
