# 从用户说法到创作任务

用于理解纯文字、有图、图文混合、多个参考和已有成品的请求。自然语言理解由代理完成，库和关键词只提供候选；不另造机械的关键词路由，不让用户填写表单或先选择专业模式。

## 先识别当前要做什么

- **讨论：**“先建议几个方向”“我们确认以后再做”。提出具体玩法，不出样张、不发生成请求；后续讨论问题仍属于讨论，直到用户明确开始。
- **新创作：**“直接做一组”“做出来，你自由发挥”。沿用已确定条件，未指定数量先问 6 款还是 9 款，此外不再等风格或前三张确认。讨论中的“自由发挥几个方案”不是生成授权。
- **局部修改：**“第五张换字”“这张调快点”。只处理指定目标，本地可完成时不生成图像。
- **继续创作：**“这个气质再来一组”“用第五张角色换九个动作”。继承用户点名喜欢的部分，其他部分继续探索；没说数量时先问 6 款还是 9 款。

已有确认和偏好在对话中继续有效。明确的新主体、数量、媒介要求覆盖旧条件；没有改变的条件继续沿用。无需每一轮重新问用户。

## 主体与输入来源

| 输入 | 保留什么 | 如何发挥 |
| --- | --- | --- |
| 仅文字，无指定主体 | 表达意图、指定文案和语气 | 可以用不同人物、动物、物件；不默认设计一个统一吉祥物 |
| 文字指定主体 | 被明确点出的特征，如橘色、墨镜、大耳朵 | 演法、比例和画风可变化；各款也不能忽然换成无关主体 |
| 要求统一角色 | 简短的轮廓、配色、标志物设定 | 同角色演不同反应，画风是否统一另看要求；不额外抽定妆图 |
| 参考图 | 相关主体的可见辨识线索 | 每款实传原图，未限媒介则跨画风；不退回通用脸 |
| 图加文字 | 图的主体与文字的用途、语气、限制 | “自拍＋打工＋欠一点”应同时满足，不只照着照片做漂亮微笑 |
| 多张图 | 用户指定的各个主体及角色关系 | 区分主角、互动对象和辅助素材；缺少决定性关系时简短询问 |
| 已有成品 | 用户要求保留的主体、气质、动作或构图 | 分清局部改动与扩展新组，不自动继承所有元素 |

“纯文字输入”不等于画面只有文字。只有用户明确让字本身表演时，才用文字动效；指定文字应保留准确字形和顺序。

不要用旧对话里的照片覆盖用户这次明确的纯文字创作，也不要因为没有图片就要求补图。角色来源足够清楚时可以直接创作。

## 三种组织方式可以叠加

1. **同一句话，多种演法。**“把‘好的呢’做得阴阳怪气。”各款保持嘴上答应、心里不满的意思。没有指定主体时，人、猫、漏气面包都可以参与。
2. **同一主体，多种反应。**“用我家狗做表情。”保留狗的花纹、耳形和体态，可演得意、嫌弃、撒娇、逃跑等，不必各款都表达同一情绪。
3. **同一场景，多种用途。**“打工人常用的一套。”覆盖收到、在改、别催、甩锅、崩溃、下班等用途；避免各款都只有崩溃。

组合例：“戴墨镜的橘猫＋打工表情＋拽一点”同时固定猫的文字特征、覆盖打工用途，并采用拽的表演气质。用户同时明确某句话时，以那句话为共同意思，不扩成无关场景菜单。

## 真实口吻的例子

| 用户可能说 | 应理解成 |
| --- | --- |
| 今天烦死了，整点发疯的 | 文字情绪起点，主体自由，各款发疯演法 |
| 别人又让我再改一版，做点表情回他 | 聊天语境起点，围绕被迫配合或崩溃；有明确对象时尊重关系语气 |
| 有人夸我漂亮，我想得意一下 | 得意回应，允许炫耀、假谦虚、庆祝等演法，不擅自当成要求本人写真 |
| 都是“我没事”，给我九种精神状态 | 指定文案与嘴硬反差，各款不随意改成别的回复 |
| 丑丑的、很欠，你自己发挥 | 风格与气质线索，自己补主体和动作，不追问专业画风名 |
| 用自拍整活，别全是漂亮微笑 | 原图身份，多种反应，允许跨画风与夸张表演 |
| 我家猫这个死鱼眼太适合上班了 | 宠物辨识＋打工用途＋冷面表演 |
| 总在崩溃的粉色饭团 | 文字角色特征＋崩溃主题，不必改成猫或真人 |
| 让咖啡杯演一个周一的我 | 物件主体，动作按杯身、把手、液面等结构适配 |
| 游戏开黑用，要得意、甩锅、求救、翻车 | 场景套图，覆盖指定用途后再补足数量 |
| 发给对象，撒娇但欠欠的 | 关系与语气起点，允许讨抱、假委屈、黏住不放 |
| 我们两个人互相甩锅 | 多主体互动，保留各自辨识，不合成一张混合脸 |
| 让“收到”两个字累到瘫倒 | 字本身是主体，准确文字结合姿势或变形，不能只画人再配字幕 |
| 以后用这个角色当我的表情形象 | 固定身份设定；当前创作继续一次出片，后续请求沿用，不启动无限自主增库 |
| 第五张很好，照这个气质再来一组 | 新一组，继承气质，不自动锁所有动作或构图 |
| 把第五张的字换成“别催了” | 指定单款局部修改，优先用干净源素材重新叠字 |

这些例子是理解样例，不是固定的十六条生产线，也不代表用户热度统计。

## 内部只留几项决定

用途或表达、主体来源、必须保留的特征与文案、允许探索的维度、数量、操作类型。用少量文字记清即可，不强制写长计划、表单或审批材料。含糊但已授权自由发挥的创意细节自行决定。

只有缺少信息会改变指定主体、角色关系、关键语气或操作范围时才问。需要建议时给具体组合，例如“冷面写实／丑萌颜艺／土味剪贴”；用户尚未选择或尚未授权开做时保持讨论，用户已说自由发挥则直接组合。
