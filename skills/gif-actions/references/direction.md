# 多玩法导演与一次出片

## 同一需求，不同脑回路

先按 [需求理解](requests.md) 判断整组的共同约束：一句话固定表达意图，一个主体固定辨识特征，一个场景固定使用范围。可以组合；同主体或同场景的各款不必同一种情绪。演法、画风、构图和节奏随用途变化，不只给温和动作换九种材质。

## 素材怎样组合

动作卡提供“这个意思怎么演”，姿势模板提供可替换的身体和道具骨架，笑点机制提供意外，风格库提供视觉语言，场景套包提供用途清单。只查本次需要的部分，不先遍历全部库。

例如“戴墨镜的橘猫，打工人，拽一点”：先覆盖收到、别催、下班等用途；再为各用途选择点头、斜眼、冲出等骨架，用巨物、反差或突变放大，配合不同风格。橘猫和墨镜保留，各款不必同一机位或材质。

没有指定主体时，可以让不同人物、动物和物件各交一个答案；指定主体后则在其他维度发散。全部写实也能改变人物表演、道具尺度、环境、分身和拼贴。一组不要求每款画风或主体都不同，差异由需求与创意决定。

| 探索方向 | 可发展的演法 |
| --- | --- |
| 夸张颜艺 | 大笑后仰、眼睛弹出、嘴巴张到离谱，仍保留角色脸型或发型 |
| 冷面荒诞 | 一本正经地表演，与失控的环境、身体或道具形成反差 |
| 剪贴穿帮 | 照片纸片倒下、飞走、被拖出画面，故意露出纸边 |
| 字面成真 | 裂开、石化、鸽了真的发生，新轮廓仍带主体特征 |
| 比例失控 | 大头小身、巨大手掌、道具挤满画面、小人被被子卷走 |
| 主客颠倒 | 工牌追人、饭碗喂人、道具反过来指挥主角 |
| 突然反转 | 看似认真办公，拉远发现整个工位都在被窝里 |
| 土味戏剧 | 施法、巨字、廉价光效、舞台机关，不靠高频闪屏 |
| 魔性重复 | 机械点头、原地弹射、分身互相推诿 |

这些是例子，不是每次必须填满的九类。查 `action.py --list-templates`，用 `--template ID` 取姿势骨架，再换主体、道具、力度和结果；找不到就即兴编。明确要求正式、道歉或安慰时可以收敛，不默认把整组做成乖巧治愈。

## 参考图身份锚点

先看图，选少量脸型、眉眼、发型、分缝或轮廓线索写入提示，每款传原图。服装配色只是辅助，不能只留下同色衣服就说是同一个人。宠物可用耳形和脸部花纹。无需量脸或写冗长特征表。

默认允许跨画风、夸张表情与变形，辨识线索仍融入新形象。只有明确要求写实才锁照片材质；写实也能大笑、做动作、分身、比例荒诞和拼贴。照片里的人不必保持原姿势不动。不做逐帧保真；已知严重偏离如实说明，不追加生成。

## 简短导演说明

每款写清以下要点即可，按输入选择说明，不需要方案文档或审批。

**纯文字输入：**

> 本款用于[共同表达／本张的场景用途]。主体是[用户指定的特征，或本款自由设计的形象]。保留[明确文字特征；无指定则省略]。采用[画风]，玩法是[荒诞事件]。关键姿势[起点→爆点→结果或重复]，节奏[突然、停顿或重复]。准确文案[后期叠加／不需要]。其他明确限制[如统一角色]。

无参考图时不传虚构路径，不沿用无关旧图；文字角色用同一份简短特征描述。用户明确统一角色时可复用已有成品参考，但不额外抽定妆图。

**参考图或图文混合：**

> 用参考图主体表现[共同表达／本张的场景用途]。实际传入相关原图，说明[每张图对应的主体或辅助作用]，保留[脸部、发型或轮廓线索]。采用[画风或拼贴手法]，玩法是[可见的荒诞事件]。关键姿势[起点→夸张峰值→结果或重复]，允许[比例、形变、卡顿、硬切]，最长停顿放在[结果]。遵守文字要求[如明确写实、别改脸、发给谁]。文案[后期叠加／不需要]。

一般从夸张、抽象出发，具体用途需要时再收敛。不要只照参考图重演原来的漂亮姿势，也不要让用户的口语气质被温和模板默认值覆盖。

## 一次帧表直接成片

路径按 [SKILL.md](../SKILL.md) 和当前工具能力选择。静态图像工具下，每款直接生成一张可合成的动作帧表，不先出锚点再扩帧。每个成品通常对应一张独立帧表，交付九宫格与每款内部帧表不是同一层。

在导演说明后附上排版要求：

> 一次画出本款 GIF 的帧表，[2 列 2 行共 4 格／3 列 2 行共 6 格]，从左到右、从上到下为播放顺序。各格画幅相同、独立完整、内容不跨界。直接画关键姿势与爆点，允许故意粗跳，不必补过渡。保留同一主体的辨识线索。无编号、边框和额外文字。

4 或 6 个状态只是便利起点，两态循环、其他网格和画幅也可按玩法使用。参考图实际传入生成工具；透明贴纸用透明背景选项，照片与拼贴可保留背景。

```sh
python scripts/build_gif.py sheet sheet.png result.gif --grid 2x2 --delay-ms 100,100,350,150
python scripts/build_gif.py sheet sheet.png result.gif --grid 3x2 --delay-ms 100,100,100,300,100,100
python scripts/caption_gif.py result.gif "我很好" captioned.gif
```

已生成纯色背景需要去除时可加 `--key`，照片渐变可加 `--dither`。不默认加 `--stabilize`，以免抹掉有意的位移。纸片倒下、剪贴逃走也直接画进帧表；不要把各款都做成同一张静图轻微摇晃，也不把生成失败的单画面自动改成轻动补救。

格子不齐时按实际返回素材切一次，不重新生成。非均匀网格用 `split_sheet.py --x-cuts ... --y-cuts ...`，再用 `pack_gif.py`。更多命令见 [编码说明](encoding.md)。

## 节奏与交付

突变和硬切适合散架、退场；停顿适合冷面；往返适合拍桌、机械点头；重复可以升级。需要连贯表演时再用连续动作，不把顺滑当作所有 GIF 的质量门槛。聊天表情可从 1–3 秒起步，不必整组同一时长；结果停一下后直接重置也可以。

每款只抽一次。生成后只切帧、编码、叠字和展示，不做联系表、原图对比或多轮 QA。收到单帧、损坏文件或缺素材时只用已有内容尝试本地导出；不能得到真正多帧 GIF 就列明该款失败，继续其余款，不复制静帧凑数。

九张原 GIF 直接放入三列表格或引用原文件的 HTML，各自按原节奏播放；无需再渲染大预览 GIF。粗糙和意外保留，让用户看整组后挑选，后续扩展属于新请求。
