# 搞怪创意起点

先想这组图替用户表达什么，再大胆组合演法。模板节省搭姿势的时间，笑点机制帮助往意料之外多走一步，两者都不是封闭目录。

| 机制 | 可以怎样放大 |
| --- | --- |
| 反差 `contrast` | 微笑配失控环境，嘴上“好的”身体却沉入地板 |
| 升级 `escalation` | 一个黑锅变成一座锅山，哭泣变成喷泉 |
| 崩坏 `collapse` | 瘫成饼、泄气、散架、融化，标志性脸部或轮廓跟着变化 |
| 冷面 `deadpan` | 主体一本正经干离谱的事，停顿比解释更有力 |
| 反转 `reversal` | 认真办公的画面拉远，整个工位原来都在被窝里 |
| 字面 `literal` | 石化、裂开、起飞、鸽了真的发生 |
| 尺度 `scale` | 大头小身、巨手、分身挤满画面、道具大到拿不动 |
| 真诚 `sincere` | 用户明确要安慰或道歉时直接表达，不强加讽刺 |

每款优先一个有记忆点的爆点，必要时混搭。同一需求可以冷面、发疯、剪贴、颜艺各交一份答案，允许一组有实用款、离谱款、实验款。三种组织方式见 [需求理解](requests.md)：同一句话的各款保持语义，同主体或同场景的各款可覆盖不同情绪和用途。

## 把用户口语变成表演

用户不用懂画风名称。以下是可组合的创作起点，不是一词对应一个动作的固定映射；先结合语境判断是在自嘲、回话还是展示角色。

| 用户的说法 | 动作和节奏可以怎样选 | 视觉可以怎样配 |
| --- | --- | --- |
| 欠一点、拽一点 | 斜眼、挑眉、慢鼓掌、假装没听见、得意后停一拍 | 巨头近景、潦草线条、一本正经的照片剪贴 |
| 癫一点、放开疯 | 原地弹射、分身互相推诿、机械重复、突然散架 | 残影、错位拼贴、像素爆散、故意比例失衡 |
| 土一点 | 正经施法、夸张登场、舞台机关露馅 | 巨字、廉价光效、红金光圈；不靠高频闪屏 |
| 丑得可爱 | 歪头瞪眼、软塌瘫倒、气鼓鼓膨胀、笨拙扑过来 | 不规则轮廓和歪斜比例，保留主体特征，别自动变回标准萌物 |
| 精神已经离职 | 身体还在点头，灵魂提包走；眼神放空，工位自行移动 | 写实冷面、纸片退场、身体与影子分离 |
| 嘴硬、我没事 | 表情维持镇定，身体泄气或处境不断失控 | 平静的脸配巨量道具、黏土融化、舞台坍塌 |
| 笑疯了 | 后仰、拍桌、笑到漏气、笑声变成喷泉或花冠 | 夸张颜艺、漫画速度线、可变形玩偶 |
| 撒娇但欠欠的 | 试探靠近、假委屈、挂住不放、突然抢走道具 | 丑萌大头、软胶、粗糙剪贴；按关系调整语气 |
| 得意但别太正经 | 假谦虚、偷偷炫耀、小成就配巨大庆祝、装酷后翻车 | 小人物巨舞台、反转镜头、土味庆功 |

同一个姿势也能表达不同意思：喝茶配“随缘”偏淡定，配“我又没说是谁”偏假装置身事外。文案与动作一起设计，指定文案保持准确；不要最后随手贴一句不相关的话。

## 强度与节奏

- 夸张：大笑到后仰、跺脚带起地板、拍桌后桌子弹走。放大幅度、比例、道具和表情。
- 抽象：物理规则失效，身体散开、工牌追人、角色掀开背景逃走；语义围绕共同需求。
- 克制：用户用途明确需要时使用，不是默认给真人降级的理由。
- 短起势、突然爆点、停顿、机械重复都可用。卡顿、硬切、粗糙线条和贴图穿帮可以成为笑点。别让各款都只小幅摆动，不靠高频闪屏代替表演。

## 真人也参与表演

原图提供身份参考，保留脸型、眉眼特点、发型或轮廓，可大笑、颜艺、变形、变成丑萌或黏土角色。只保留同色衣服却换成通用角色，不算保留本人。

明确要求写实时保持照片材质，仍大胆运用人物表演、比例、分身、道具、剪贴和环境。优雅写真也能成为夸张反应，不必保持原表情和姿势。身份和玩法在生成前约定，偶然怪异不触发重抽；已知严重丢失辨识度如实说明。

## 模板与即兴

`action.py --list-templates` 提供常用姿势骨架，`--template ID` 展开替换点与升级变体。“瘫倒”可以是泄气玩偶、写真纸片倒下或像素角色散成方块；“探头”可以是巨头挤进画面、多个分身轮流探头。

找不到就直接编，不退回保守动作。可复用骨架按 [贡献指南](../../../CONTRIBUTING.md) 收入库。整组创意不固定为九类，也不要求每次用完全部画风。
