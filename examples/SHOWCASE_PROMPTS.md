# 样片墙提示词

这 8 条用来给 README 生成真实样片，覆盖不同笑点和风格。先把技能装进 Codex，然后逐条发送。第 1 条通过后，把它作为第 2 条及之后同角色样片的参考图，这样还能顺便检验角色一致性。

生成好的 GIF 放到 `examples/showcase/`，文件名用下面的编号。

| 编号 | 发给 Codex 的话 | 要验证什么 |
| --- | --- | --- |
| `01-defense-broken` | 用 $gif-actions 做“破防了”，原创饭团角色，戴红围巾，扁平贴纸风格，夸张档。 | 崩坏、角色设定 |
| `02-pie-in-the-sky` | 用 $gif-actions 做“老板画大饼”，沿用这个饭团角色，沙雕手绘风格，抽象档。 | 反转、换风格后的角色一致性 |
| `03-smile-burning` | 用 $gif-actions 做“我没事”，微笑着身后着火那张，沿用饭团角色，黏土风格。 | 反差、多层变化 |
| `04-cat-cup` | 用 $gif-actions 做一只橘猫面无表情把杯子推下桌，毛绒玩偶风格。 | 冷面、停顿节奏 |
| `05-carry-the-pot` | 用 $gif-actions 做“背锅”，火柴人风格，黑锅是唯一有颜色的东西。 | 升级、极简风格 |

每条都看这几项，并记下不通过的地方：

0. 交付的是多帧 GIF 吗？没说数量时先问了 6 款还是 9 款吗？有没有停在 PNG 或要求装插件？
1. 整组的玩法够不够不同？
2. 笑点在成片里演出来了吗？还是只有动作？
3. 爆点缩到 96 像素还能看懂吗？
4. 换风格、换动作后角色还是同一个吗？
